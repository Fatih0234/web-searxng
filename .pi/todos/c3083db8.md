**File:** `src/webx/cli.py` (argparse, no new abstractions)

**Commands to finalize:**
- `webx init [--force-templates] [--show-path]` (phase2)
- `webx doctor` (inspection only)
- `webx up` (ensure_running explicit)
- `webx stop` (compose stop, idempotent)
- `webx status [--json]`
- `webx search QUERY [options]` (phase4)
- `webx read URL [--max-chars N] [--json] [--links] [--no-tables] [--precision] [--recall]` (phase5)
- optional `webx logs` (compose logs helper)

**Core class:** `WebX` facade in `src/webx/core.py` or `__init__.py` exposing search/read/start_search_service/stop_search_service/status/doctor; CLI + MCP both call it, no shell-out between them.

**Behavior:**
- stdout = data only; stderr = diagnostics/lifecycle/errors
- `--verbose` optional debug; never leak secrets
- exit codes: 0 success, 2 usage/validation, 3 runtime/docker unavailable, 4 SearXNG failure, 5 unsafe URL, 6 fetch/extraction failure, 7 unsupported content type
- works from any CWD, not reliant on repo
