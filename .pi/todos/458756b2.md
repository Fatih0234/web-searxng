**Goal:** Enforce SSRF/private-network denial BEFORE any fetch; own HTTP fetch, then trafilatura extraction. Never use trafilatura.fetch_url as primary path.

**Files:** `src/webx/security.py` (URL parsing, hostname/IP checks, redirect validation, private denial), `src/webx/reader.py` (WebReader)

**Security (05 full before coding):**
- Allow only http/https; reject file, ftp, data, javascript, bare paths, credential-bearing URLs (user:pass@host)
- Normalize hostname, resolve via socket.getaddrinfo, inspect every IPv4/IPv6 via ipaddress: deny loopback, RFC1918, CGNAT? explicitly listed: localhost, 127/8, 10/8, 172.16/12, 192.168/16, ::1, unique-local, link-local (169.254.0.0/16, fe80::/10), multicast, unspecified, reserved, metadata 169.254.169.254, and configured WEBX_SEARXNG_URL host itself
- No --allow-private in v1
- Document DNS rebinding limitation; mitigate by validating every redirect target

**Redirect policy:** manual loop, max 5, resolve Location against current URL, re-validate URL+IP each hop, fail on loops/excess.

**HTTP limits (configurable with hard caps):**
- connect ~5s, overall ~15s, max 10 MiB streamed (check Content-Length pre-download + enforce while streaming), User-Agent webx/<version> local-research-tool, no browser masquerade
- Allowed types: text/html, application/xhtml+xml, text/plain, markdown-like, optionally json/xml text; reject binary with exit 7
- Streaming read to avoid OOM

**Extraction:** pass raw body to trafilatura.extract(output_format="markdown", url=final_url, include_comments=False, include_tables=True default, include_links=False default, with_metadata=False); fallback html2txt if empty; truncate AFTER extraction to max_chars default ~40000 at sensible boundary, set truncated/chars metadata.

**Tests:** Mock resolver + httpx; allow/deny matrix from 07 (localhost, private ranges, file/ftp, credentials, ::1, 169.254.169.254); redirect to private must be denied before second fetch; oversized Content-Length and streamed limit; content-type policy; truncation flag.

**Risk:** DNS rebinding not fully eliminated; streaming + ipaddress logic must be robust.
