**Goal:** `webx init` materializes runtime dir idempotently, never overwrites secret without reset.

**Files:** `src/webx/config.py` (resolve data dir via platformdirs, env overrides WEBX_DATA_DIR, WEBX_SEARXNG_URL etc., startup/search/read timeouts, max bytes/chars), `src/webx/runtime.py` or part of `lifecycle.py` init logic, `src/webx/cli.py` init subcommand.

**Behavior (02 Phase2 + 03 CLI):**
1. mkdir runtime_dir (platformdirs user_data_dir/webx)
2. copy/update compose.yml + settings.yml from package assets (check --force-templates vs preserve)
3. generate .env with secrets.token_hex(32) if absent, chmod 0600 where supported
4. create cache/ subdir
5. print runtime path & what was created (human readable, stderr/stdout allowed for admin cmds)
6. idempotent: second run without --force-templates leaves existing files, never rotates secret

**Env vars:** WEBX_DATA_DIR, WEBX_SEARXNG_URL, WEBX_DOCKER_CMD, WEBX_STARTUP_TIMEOUT, WEBX_SEARCH_TIMEOUT, WEBX_READ_TIMEOUT, WEBX_MAX_RESPONSE_BYTES, WEBX_MAX_READ_CHARS, WEBX_MCP_STOP_ON_EXIT, SEARXNG_IMAGE via .env

**Validation:** Unit tests with TemporaryDirectory override via WEBX_DATA_DIR; verify idempotence & secret preserved; check --show-path/--force-templates.

**Risk:** platformdirs path differs per OS; test must mock/override. Permission handling on Windows.
